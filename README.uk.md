**Сучасний музичний програвач для Windows, створений на C# та .NET 8.**

AUREON — компактний програвач для вашої локальної музичної колекції. Він поєднує 10-смуговий еквалайзер із регуляторами басу, стереобази та суббасу, зміну швидкості зі збереженням висоти тону, плейлисти у вкладках, обкладинки, сповіщення про трек і вбудований доступ до онлайн-музичних сервісів. Усе це в темному безрамковому вікні, яке можна згорнути до невеликого міні-плеєра.

## Можливості

### Відтворення
- Підтримка аудіофайлів MP3, FLAC, WAV, AIFF, WMA, M4A, AAC та MP4.
- Плавне наростання та згасання гучності між треками.
- Режими випадкового відтворення та повтору.
- Швидкість відтворення від 0,5× до 2× **без зміни висоти тону** (SoundTouch).
- Гучність до 150% з налаштовуваною межею (100%, 125% або 150%).
- Регулювання балансу лівого та правого каналів.
- Візуалізація аудіоспектра в реальному часі.

### Звук
- 10-смуговий еквалайзер із готовими пресетами (Плоский, Бас, Високі, Вокал, Рок, Поп, Джаз).
- Збереження, застосування та видалення власних пресетів.
- Три крутилки ефектів: **Бас**, **Простір** (віртуалайзер) і **Суббас**.
- Один перемикач вмикає та вимикає еквалайзер разом з усіма ефектами.

### Бібліотека та плейлисти
- Плейлисти у вкладках: додавання папки, створення порожнього плейлиста, перейменування, очищення та закриття вкладок.
- Перетягування файлів і цілих папок у список або на смугу вкладок.
- Миттєвий пошук у поточному плейлисті.
- Оцінки зірками (1–5) для кожного треку та загальна тривалість плейлиста.
- Плейлисти, оцінки та налаштування зберігаються автоматично.
- Відкриття аудіофайлів через AUREON із Провідника: якщо програма призначена за замовчуванням, файли додаються до плейлиста.

### Інтерфейс
- Власне темне вікно із заокругленими кутами та вбудованим заголовком.
- Обкладинка з тегів треку або із зображень у папці (`cover.jpg`, `folder.jpg`, підпапка `Artwork` тощо).
- Спливаюче сповіщення з обкладинкою, назвою, виконавцем і альбомом при зміні треку.
- Міні-плеєр: подвійний клік по обкладинці згортає вікно, ще один клік розгортає.
- Гарячі клавіші для основних дій (див. нижче).

### Онлайн-музика
- YouTube Music, Spotify та Apple Music усередині програвача через Microsoft Edge WebView2.
- Сервіс обирається в контекстному меню кнопки ♫ у заголовку вікна.
- Дані входу зберігаються в локальному профілі WebView2 на вашому ПК; їх можна видалити з того самого меню.

## Гарячі клавіші

| Комбінація | Дія |
|---|---|
| `Пробіл` | Відтворення / пауза |
| `Ctrl` + `→` / `Ctrl` + `←` | Наступний / попередній трек |
| `Ctrl` + `Tab` / `Ctrl` + `Shift` + `Tab` | Наступна / попередня вкладка плейлиста |
| `Ctrl` + `O` | Додати треки |
| `Ctrl` + `E` | Показати / сховати еквалайзер |
| `Ctrl` + `R` | Випадкове відтворення |
| `Ctrl` + `T` | Сповіщення про трек |
| `Ctrl` + `Delete` | Очистити поточний плейлист |
| `Esc` | Зупинити відтворення |

## Системні вимоги

- Windows 10 або Windows 11, x64.
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (потрібен для онлайн-сервісів).
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) для збірок, що залежать від фреймворку.

## Збірка з вихідного коду

1. Встановіть Visual Studio з робочим навантаженням **.NET desktop development**.
2. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/CapitanSashko/AUREON.git
   ```

3. Відкрийте `MP3 Play.sln` у Visual Studio.
4. Відновіть пакети NuGet.
5. Зберіть проєкт у конфігурації **Release**.

## Де AUREON зберігає дані

Налаштування лежать поруч із виконуваним файлом у звичайних текстових файлах:

| Папка / файл | Вміст |
|---|---|
| `playlist/` | Плейлисти (`.m3u8`), список вкладок та оцінки треків |
| `equalizer/` | Налаштування еквалайзера, власні пресети та значення ефектів |
| `toast.cfg` | Увімкнені / вимкнені сповіщення про трек |

Профіль WebView2 (онлайн-сервіси) зберігається в `%LocalAppData%\AUREON\webview2`.

## Технології

- C# та .NET 8
- Windows Forms
- [NAudio](https://github.com/naudio/NAudio): відтворення та обробка звуку
- [SoundTouch.Net](https://github.com/owoudenberg/soundtouch.net): зміна темпу зі збереженням висоти тону
- [TagLib#](https://github.com/mono/taglib-sharp): теги, обкладинки та тривалість
- Microsoft Edge WebView2: онлайн-музичні сервіси

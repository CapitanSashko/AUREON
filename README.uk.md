## Можливості



### Бібліотека та плейлисти
- Плейлисти у вкладках: додавання папки, створення порожнього плейлиста, перейменування, очищення та закриття вкладок.
- Перетягування файлів і цілих папок у список або на смугу вкладок.
- Миттєвий пошук у поточному плейлисті.
- Оцінки зірками (1–5) для кожного треку та загальна тривалість плейлиста.
- Плейлисти, оцінки та налаштування зберігаються автоматично.
- Відкриття аудіофайлів через AUREON із Провідника: якщо програма призначена за замовчуванням, файли додаються до плейлиста.

### Інтерфейс
- Власне темне вікно із заокругленими кутами та вбудованим заголовком.
- Обкладинка з тегів треку або із зображень у папці (`cover.jpg`, `folder.jpg`, підпапка `Artwork` тощо).
- Спливаюче сповіщення з обкладинкою, назвою, виконавцем і альбомом при зміні треку.
- Міні-плеєр: подвійний клік по обкладинці згортає вікно, ще один клік розгортає.
- Гарячі клавіші для основних дій (див. нижче).

### Онлайн-музика
- YouTube Music, Spotify та Apple Music усередині програвача через Microsoft Edge WebView2.
- Сервіс обирається в контекстному меню кнопки ♫ у заголовку вікна.
- Дані входу зберігаються в локальному профілі WebView2 на вашому ПК; їх можна видалити з того самого меню.

## Де AUREON зберігає дані

Налаштування лежать поруч із виконуваним файлом у звичайних текстових файлах:

| Папка / файл | Вміст |
|---|---|
| `playlist/` | Плейлисти (`.m3u8`), список вкладок та оцінки треків |
| `equalizer/` | Налаштування еквалайзера, власні пресети та значення ефектів |
| `toast.cfg` | Увімкнені / вимкнені сповіщення про трек |

Профіль WebView2 (онлайн-сервіси) зберігається в `%LocalAppData%\AUREON\webview2`.

## Технології

- C# та .NET 8
- Windows Forms
- [NAudio](https://github.com/naudio/NAudio): відтворення та обробка звуку
- [SoundTouch.Net](https://github.com/owoudenberg/soundtouch.net): зміна темпу зі збереженням висоти тону
- [TagLib#](https://github.com/mono/taglib-sharp): теги, обкладинки та тривалість
- Microsoft Edge WebView2: онлайн-музичні сервіси
